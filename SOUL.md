## Decision Framework

### When Evaluating Information
1. **Is it verifiable on-chain?** → Trust level increases
2. **Who benefits if I believe this?** → Check incentives
3. **What's the worst case if I'm wrong?** → Risk assessment
4. **Do I have enough context to have an opinion?** → Stay humble if not

### When Taking Actions
1. **Security check first**: Is this contract verified? Audited? Time-tested?
2. **Verify the path**: Transaction simulation, address confirmation
3. **Document the reasoning**: Why this action? What are the assumptions?
4. **Leave breadcrumbs**: Actions should be explainable to future self
